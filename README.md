# Consumer Complaint Root-Cause Analytics & Model Validation

An end-to-end analytics project on the U.S. Consumer Financial Protection
Bureau's public Consumer Complaint Database — root-cause trend analysis
in SQL on Google BigQuery, plus a full validation framework for a
text-classification model's output.

## Why this project
Consumer complaints data is messy, high-volume, and genuinely useful:
it's a real-world testbed for trend analysis, root-cause identification,
and — increasingly — for evaluating whether an automated
classification system (rule-based, ML, or LLM-based) can be trusted to
categorize incoming complaints correctly. That last piece is what most
"data analyst" portfolio projects skip, so it's the focus here.

## What it does
1. **SQL analysis on BigQuery's public dataset** — no ingestion pipeline
   needed. Queries trend complaint volume over time, surface the leading
   root-cause ("Issue") per product and per state, and build a
   regulatory-style SLA report (timely-response rate and dispute rate
   by company).
2. **A root-cause classifier** — a TF-IDF + logistic regression baseline
   that predicts a complaint's root-cause category from its free-text
   narrative.
3. **A model validation framework** — the actual point of the project.
   Rather than stopping at "the model works," it produces accuracy,
   per-class precision/recall, a confusion matrix, and a written
   error-pattern analysis: which categories get confused, why, and what
   that implies for improving the model (more training examples,
   better features, or a human-in-the-loop review step for low-
   confidence predictions). The same harness is designed to validate a
   real LLM's classifications just as easily as the baseline model —
   see the comments in `scripts/04_complaint_classifier_validation.py`.

## Tech stack
Google BigQuery (SQL), Python (pandas, scikit-learn, matplotlib)

## Project structure
```
scripts/
  01_bigquery_queries.sql              -- SQL against the live public dataset
  02_generate_sample_data.py           -- generates a local test dataset
  03_eda_and_trends.py                 -- trend & root-cause analysis + charts
  04_complaint_classifier_validation.py -- classifier + validation framework
  05_bigquery_connector.py             -- pulls real data once BigQuery is set up
data/
  sample_complaints.csv                -- schema-accurate synthetic test data
outputs/
  charts, validation report, and summary CSVs from a sample run
```

## Running it
```bash
# Test the full pipeline locally first (no cloud account needed):
python scripts/02_generate_sample_data.py
python scripts/03_eda_and_trends.py
python scripts/04_complaint_classifier_validation.py

# Then connect to the real public dataset on BigQuery:
pip install google-cloud-bigquery pandas db-dtypes
gcloud auth application-default login
python scripts/05_bigquery_connector.py --project YOUR_GCP_PROJECT_ID
```

The public dataset lives at `bigquery-public-data.cfpb_complaints.complaint_database`
— free to query under BigQuery's on-demand tier, no data download required.

## Note on the sample data
`data/sample_complaints.csv` is a schema-accurate **synthetic** dataset
generated by `scripts/02_generate_sample_data.py`, used to test and
demo the pipeline without requiring a live cloud connection. Real
consumer narratives are not reproduced here. Swap in
`05_bigquery_connector.py`'s output to run the same analysis on genuine
CFPB data.

## Data source
U.S. Consumer Financial Protection Bureau, Consumer Complaint Database
(public domain). https://www.consumerfinance.gov/data-research/consumer-complaints/
